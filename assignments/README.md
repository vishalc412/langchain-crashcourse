# Course Assignments

## Overview

This folder contains all graded assignments for the LangChain & LangGraph course. Each assignment is designed to test your understanding and practical skills.

## Assignment Structure

Each assignment includes:
- Clear objectives
- Requirements
- Starter code
- Test cases
- Grading rubric
- Submission checklist

## Grading Scale

| Grade | Percentage | Description |
|-------|------------|-------------|
| A | 90-100% | Excellent - All requirements met with exceptional quality |
| B | 80-89% | Good - All requirements met |
| C | 70-79% | Satisfactory - Most requirements met |
| D | 60-69% | Needs Improvement - Some requirements met |
| F | <60% | Incomplete - Major requirements missing |

## How to Submit

1. Complete the assignment
2. Run all test cases
3. Verify against the rubric
4. Self-grade your work
5. (Optional) Share for peer review

## Honor Code

- Complete assignments independently
- Use the solutions only after attempting
- Document any external resources used
